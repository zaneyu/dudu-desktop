# Product

## Register

product

## Users

The primary user is the owner's girlfriend, a non-technical Windows 11 user who wants a gentle desktop companion without having to manage software complexity. The owner configures private pairing and installation. Daily workflows are quick: glance at Dudu, respond to a reminder, start a focus session, read a private note, or adjust one setting.

## Product Purpose

Dudu Desktop Companion combines an affectionate animated desktop pet with practical reminders, focus tools, countdowns, comfort interactions, and end-to-end encrypted love notes. Success means setup takes under two minutes, ambient behavior never becomes disruptive, private content stays private, and every important function remains understandable from standard Windows controls.

## Brand Personality

Warm, calm, considerate. Dudu may be playful and expressive, while the application shell remains trustworthy, restrained, and native to Windows 11.

## Anti-references

Do not resemble a themed web dashboard, a dense productivity suite, a childish mobile game, or a glass-heavy AI-generated concept. Avoid decorative gradients, oversized cards, novelty controls, excessive animation, and romantic copy that feels performative or embarrassing.

## Design Principles

1. Affection without interruption: ambient moments yield to quiet hours, focus, fullscreen work, and explicit pause controls.
2. Native familiarity: use standard Windows navigation, controls, focus behavior, keyboard access, and system materials.
3. Private by default: explain local storage and encrypted pairing plainly, without exposing technical machinery in ordinary flows.
4. One clear next action: onboarding and empty states should be understandable at a glance.
5. Dudu carries the delight: keep the shell visually quiet so the pet remains the memorable element.

## Accessibility & Inclusion

Meet Windows accessibility conventions with keyboard navigation, stable automation IDs, high-contrast resources, visible focus indicators, non-color status cues, readable scaling, and reduced-motion behavior available from onboarding onward.
